# Bexley Pay
Accept crypto from any chain. You get USDC on NEAR. Built on the NEAR Intents 1Click API.

## Run it
1. Install Node.js (nodejs.org, the LTS version).
2. In this folder, copy `.env.example` to `.env` and fill in your API key and NEAR account.
3. Run `npm install`, then `npm start`.
4. Open http://localhost:3000
